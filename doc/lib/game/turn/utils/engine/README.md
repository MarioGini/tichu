# lib/game/turn/utils/engine/

Low-level engine utility modules for deterministic turn/round progression.

## Implemented Here
- `dealing.dart`: dealing setup and distribution helpers.
- `grand_tichu.dart`: grand tichu timing/effects helpers (including one grand-tichu call max per team).
- `hand_utils.dart`: hand mutation and lookup helpers.
- `schupf.dart`: engine-level schupf execution helpers.
- `trick_resolution.dart`: trick winner/cleanup resolution logic.
- `turn_order.dart`: turn sequencing and seat-order helpers.
