# lib/

Mirror root for source folders under `lib/**`.

## Implemented Here
- `main.dart`: app bootstrap, theme setup, and root routing into screens.

## Child Folders
- [agents](agents/README.md): AI strategy and decision policies.
- [game](game/README.md): engine contracts, projection seam, and game rule orchestration.
- [headless](headless/README.md): CLI/headless simulation entrypoint.
- [screens](screens/README.md): screen-level UI composition.
- [services](services/README.md): backend/sound service adapters.
- [theme](theme/README.md): app theming primitives.
- [widgets](widgets/README.md): reusable game UI widgets.
