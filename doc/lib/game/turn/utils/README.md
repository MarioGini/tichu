# lib/game/turn/utils/

Reusable utility logic for card relations and combination validation used by turn rules and move generation.

## Implemented Here
- `bomb_utils.dart`: bomb detection/comparison helpers.
- `card_utils.dart`: base card ordering and normalization helpers.
- `full_house_utils.dart`: full-house validation/comparison.
- `pair_straight_utils.dart`: pair-straight validation/comparison.
- `straight_utils.dart`: straight validation/comparison.

## Child Folders
- [engine](engine/README.md): lower-level turn engine helper modules.
